03 源码

代码怎么组织的

解释器管线一目了然：词法 → 语法 → AST → 解释执行或字节码 VM，中间是值系统与标记-清除 GC。

lang/
src/
├─ include/     公共头文件 (l_config.h / l_hal.h ...)
├─ core/        解释器核心
│   lexer.c     词法分析（0x / 0b 字面量）
│   ast.c       语法树节点
│   parser.c    递归下降语法分析
│   value.c     动态值系统
│   gc.c        标记-清除垃圾回收
│   interp.c    解释器、方法派发、异常
│   builtins.c  内置函数与 help()
│   bytecode.c  字节码序列化
│   compiler.c  源码到字节码
│   vm.c        栈式虚拟机
├─ stdlib/      标准库 (io / net / math / hw / time / sys ...)
└─ main/
    main.c      CLI 入口

回归测试

tests/ 下每组 .l 都配一份 .out 期望输出，覆盖基础语法、闭包、集合、GC、字节码、硬件对象与网络模块。

PowerShell
powershell -ExecutionPolicy Bypass -File .\run_tests.ps1

编辑器支持

仓库内置 VS Code 语法高亮扩展（editors/vscode），包含 .l 的 TextMate 文法与语言配置，可本地安装使用。

PowerShell
powershell -ExecutionPolicy Bypass -File .\scripts\install_vscode_ext.ps1
