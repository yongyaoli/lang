Language Reference

Syntax, types and built-in objects

Compact C-like syntax with dynamic types and an interactive feel. The full grammar lives in L_EBNF.md; inside the REPL, help() is the offline manual.

01 Basics

Variables, types and operators

Variables and constants

vars.l
let count = 10;             // mutable
let empty;                  // defaults to nil
const LED_PIN = 2;          // reassignment raises a runtime error

Operators

Arithmetic + - * / %, comparison == != < <= > >=, logical and / or (short-circuit) and not / !, plus the full set of C bitwise operators and a ternary expression.

ops.l
let reg = (1 << 4) | 0x03;        // 0x13
let high = (0xCAFE >> 8) & 0xFF;   // 0xCA
let level = (temp > 30) ? "HIGH" : "NORMAL";

Control flow

flow.l
if count > 0 {          // no parentheses required
    print("positive");
} else {
    print("non-positive");
}

for let i = 0; i < 5; i = i + 1 {
    if i == 2 { continue; }
    print(i);
}

let n = 0;
while n < 3 { n = n + 1; }

02 Functions

First-class functions and closures

Functions can be assigned, passed, returned, and they capture their defining scope.

counter.l
fn make_counter(start) {
    let n = start;
    return fn(step) {
        n = n + step;
        return n;
    };
}

let c = make_counter(10);
print(c(5), c(3));      // 15 18
methods.l
print("  hello esp32  ".trim().upper().split(" "));
// ["HELLO", "ESP32"]

print([3, 1, 4, 2].sort().map(fn(x) { return x * 10; }));
// [10, 20, 30, 40]

let sensor = {
    addr: 0x3C,
    scale: 2,
    read: fn(raw) { return raw * self.scale; }
};
print(sensor.read(21));  // 42

Map methods get an implicit self binding; you may also declare fn(self, ...) explicitly.

03 Exceptions

Structured try / catch / throw

Every syntax or runtime error becomes an object carrying type, message, file, line, column, source line and stack.

except.l
try {
    throw { code: 500, message: "sensor timeout" };
} catch (e) {
    print(e.type, e.message);
    print(e.file + ":" + str(e.line) + ":" + str(e.col));
    print(e.source);   // offending source line
    print(e.stack);    // stack trace string
}
uncaught output
[sensor.l:12:16] runtime error: division by zero
    12 |     return 100 / scale;
       |                ^
  stack trace:
    at read_sensor (sensor.l:12:16)
    at main_loop (sensor.l:20:14)
    at <main> (sensor.l:25:1)

Exit codes: 65 syntax error, 70 runtime error, 74 unreadable file.

04 Modules

import and bytecode

Built-in hardware modules need no filesystem; local modules are imported by path, cached, and aliased with as.

import.l
import "esp32" as hw;          // built-in hardware module
import "./utils/math_ext.l" as m;

print(m.clamp(ADC(34).read(), 0, 4095));
bytecode
l -c main.l -o main.lc    # compile to bytecode
l main.lc                 # run bytecode
l -d main.l               # disassemble opcodes

Bytecode can be written to the l_script partition; the LBC1 magic makes the board run it on the stack VM, skipping lexing and parsing.

05 Hardware

Peripheral objects at a glance

Constructors behave identically on real hardware; on PC the host-sim layer takes over and accepts injected data.

Pin digital IO

Pin(pin, [mode="out"], [val]) or the shorthand pin(pin). Modes: "out", "in", "in_pullup", "in_pulldown", "open_drain".

Methods: .on() / .high(), .off() / .low(), .toggle(), .value([0|1]), .mode([m]), .info(). Configuration calls return the object, so calls chain.

PWM pulse width modulation

PWM(pin, [freq=1000], [duty=0]), 10-bit duty range 0..1023.

Methods: .freq([hz]), .duty([0..1023]), .duty_percent([0..100]), .stop() / .deinit().

ADC analog input

ADC(pin, [atten="11db"]); the constructor validates that the pin has an ADC channel.

Methods: .read() (0..4095), .read_mv(), .read_uv(), .atten(db), .write_sim(raw).

I2C bus and registers

I2C([bus=0], [sda], [scl], [freq]).

Methods: .scan(), .write(addr, data), .read(addr, len), .write_reg(addr, reg, data), .read_reg(addr, reg, len), .sim_device(addr).

SPI full duplex

SPI([bus=1], [sck], [mosi], [miso], [freq]).

Methods: .transfer(data) / .xfer(data) returning bytes, .write(data), .read(len, [fill]).

UART serial port

UART([port=1], [baud=115200], [tx], [rx]).

Methods: .write(data), .any(), .read([len]), .read_str(), .sim_input(data).

bytes byte buffer

bytes(len | array | str) with indexed writes such as b[0] = 0xFF.

Methods: .len(), .hex([sep]), .to_str(), .to_array(), .fill(b), .slice(s, [e]), .u16_be(off), .u16_le(off), .set_u16_be(off, v), .set_u16_le(off, v).

06 Network

WiFi and IoT

Networking, time sync and HTTP live in the standard library; on PC they run against a simulation so logic can be tested first.

telemetry.l
if wifi_connect("Home", "12345678") {
    sntp_sync();
    let r = http_post("https://api.example.com/ingest",
                      str({ temp: ADC(34).read_mv(), at: time() }));
    print(r.status, r.body);
}
