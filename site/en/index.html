Write a script.
Light up a chip.

L (lang) is a tiny scripting language implemented from scratch in pure C99 — no third-party dependencies at all. The same .l file drives GPIO, PWM, ADC, I2C, SPI and UART on an ESP32, or runs offline on Windows, Linux and macOS.

01 Thirty seconds

No IDE, no project setup

One interpreter, one .l file, one board. Trailing semicolons are optional and multi-line blocks are detected automatically.

blink.l
const LED = 2;

pin(LED).on();                 // light the on-board LED
PWM(LED, 5000, 512);           // 5 kHz, 50% duty

print(ESP32.chip());           // ESP32 / ESP32-S3 / ESP32-C3 / ESP32-C6
print(ESP32.free_heap(), "B"); // remaining heap

try {
    Pin(6, "out");             // GPIO 6 is internal SPI flash
} catch (e) {
    print(e.message);          // caught by the pin guard
}
sample output
$ l blink.l
ESP32-S3
198432 B
[blink.l:9:3] runtime error: GPIO 6 is reserved for internal SPI flash
    9 |     Pin(6, "out");
      |     ^

No board at hand? l falls back to host-sim: hardware calls are emulated on the host, and your script does not change.

02 Why L

Keep the complexity in the interpreter,
keep the scripting simple

Most embedded friction comes from toolchains, filesystems, flashing and debugging — not from your logic. L folds all of that into a single base firmware.

01

Zero dependencies, one-line build

No lex, yacc, LLVM or external libraries. The whole interpreter plus stdlib is a few thousand lines of C99, buildable with GCC, Clang, MSVC or ESP-IDF.

02

One script, two runtimes

A single HAL (l_hal.h): ESP-IDF drivers on real hardware, host-sim on your machine. ESP32.set_chip("ESP32-C3") switches pin rules too.

03

Scripts in raw flash, no filesystem

A dedicated l_script partition with a 16-byte header and IEEE 802.3 CRC32, executed in place through esp_partition_mmap — zero SRAM copy, auto-start on boot.

04

0.2-second edit cycle

Flash the base firmware once. Afterwards upload("COM3", "main.l") pushes over serial, or flash straight from the browser with Web Serial. No rebuild.

05

Errors point at a column

[file:line:col] plus the source line, a ^ marker and a full stack trace — together with try / catch for graceful recovery.

06

First-class VS Code / CodeBuddy support

The official extension adds syntax highlighting, class & method hover, Ctrl+Click go-to-definition, CodeLens reference counts and a dedicated .l file icon. The Windows installer registers everything for you.

Hardware objects are just objects

No special syntax: pin(2).on() is a method call. Chain it, store it, put it in an array, capture it in a closure.

04 Install & firmware

Two paths, pick one

Install the interpreter on your computer, and flash the base firmware on the board. Neither requires a cloud build or a multi-gigabyte toolchain.

Install l on your computer

On Windows the installer handles PATH for you. On Linux and macOS the script installs system-wide with sudo, or falls back to ~/.local/bin.
