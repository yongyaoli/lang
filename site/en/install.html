Install

Get l running in one command

Windows, Linux and macOS are supported. The installer deploys the interpreter and stdlib, writes PATH and associates .l files — no runtime to preinstall.

01 Pick a platform

Windows installer recommended lang-setup-windows-x86_64.exe Windows 10/11 · x64 Portable zip lang-windows-x86_64.zip no registry, unzip and run

Using the installer

  1. Download and run the setup

    Installs to %LOCALAPPDATA%\Programs\lang by default; no admin rights needed.

  2. Follow the wizard

    User-level PATH is written automatically and the app is registered in Apps & features for one-click uninstall.

  3. Open a new terminal

    Already-open windows keep the old PATH; start a fresh CMD or PowerShell.

PowerShell
PS> l --version
L 0.1.9

PS> l
Type "help", "copyright", "license" or "exit" for more information.
ESP32 快捷命令: ports() | upload("COM3", "main.l") | connect("COM3") | help("esp32")
>>>

If the release page has no installer attached yet, use the script below or build from source (third tab).

Using the script

PowerShell
git clone https://github.com/yongyaoli/lang
cd lang
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
Linux x86_64 lang-linux-x86_64.tar.gz prebuilt binary + install.sh macOS Apple Silicon lang-macos-arm64.tar.gz M1 / M2 / M3 / M4 · prebuilt macOS Intel lang-macos-x86_64.tar.gz x86_64 · prebuilt

Unpack and run bash install.sh. For other architectures (ARM servers, RISC-V) use the lang-unix.zip source bundle or build from source.

One-line script

The script detects your OS and architecture, builds or unpacks the right binary, and puts l on your executable path.

bash
git clone https://github.com/yongyaoli/lang
cd lang
bash ./scripts/install.sh

Where it installs

1. With sudo: /usr/local/bin/l.
2. Without root: falls back to ~/.local/bin/l.
3. Adds the right PATH line to ~/.bashrc, ~/.zshrc or ~/.profile.

Uninstall

bash
bash ./scripts/uninstall.sh

On macOS, if Gatekeeper blocks the binary, allow it once in System Settings → Privacy & Security, or build from source.

All you need is a C compiler

No lex, no yacc, no LLVM, no third-party libraries. This single command is the entire build:

Linux / macOS
gcc -O2 -Wall -Wextra -Isrc/include src/core/*.c src/stdlib/*.c \
    src/main/main.c -o l
Windows · PowerShell
gcc -O2 -Wall -Wextra -Isrc/include src/core/*.c src/stdlib/*.c src/main/main.c `
    -lwininet -lws2_32 -static -o l.exe

Minimal build for bare metal

Drop filesystem and process modules for a smaller ESP32 interpreter:
-DL_WITH_STDLIB_IO=0 -DL_WITH_STDLIB_SYS=0

Missing bytecode.c, compiler.c or vm.c shows up as undefined symbols at link time.

02 Verify

Three commands to confirm

terminal
l --version      # print the version
l                # enter the REPL
l main.l         # run a script file
expected
$ l --version
L 0.1.9

$ l
Type "help", "copyright", "license" or "exit" for more information.
>>> print("hello")
hello

If the shell says command not found, reopen the terminal or check PATH. Use where l on Windows, which l elsewhere.

03 Distribute

Package your own copy

To hand l to a colleague or ship it inside a private network, one script produces the installer and the zips.

PowerShell
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
OutputPurpose
lang-setup-windows-x86_64.exeWindows standalone installer
lang-windows-x86_64.zipWindows portable build
lang-unix.zipLinux / macOS package
l-language-support-0.3.0.vsixVS Code syntax highlighting & hover docs

The script bumps the patch version via scripts/bump_version.ps1, then builds and packs everything into dist/.
