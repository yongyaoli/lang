Language Reference

语法、类型与内置对象

C 语言的紧凑语法，加上脚本语言的动态类型与交互式体验。完整文法见 L_EBNF.md；在 REPL 里随时输入 help() 也能查到全部内置函数。

01 基础

变量、类型与运算符

变量与常量

vars.l
let count = 10;             // 可变变量
let empty;                  // 未初始化，默认 nil
const LED_PIN = 2;          // 常量：二次赋值会抛运行时错误

八种核心类型

类型字面量与构造说明
int42, 0xFF, 0b1010_000132 位有符号整数；7 / 2 == 3（C 语义整除）
float3.14, 2.5e-3, 7 / 2.064 位双精度；与 int 混合运算自动提升
booltrue, false只有 false 与 nil 为假，0 与 "" 均为真
nilnil空值
string"你好\nL"不可变 UTF-8 字符串，支持 +、下标与 .trim() 等方法
bytesbytes(4), bytes([0x48, 0x69])定长可变字节缓冲，为 I2C / SPI / UART 而生
array[1, "a", true]动态数组，.push() / .map() / .filter() / .sort()
map{ id: 1, "name": "ESP32" }字符串键字典，m.id 与 m["id"] 等价
functionfn(x) { return x + 1; }一等函数，带词法闭包
objPin(2)原生硬件对象，方法表存放在 .rodata，零 RAM 开销

运算符

算术 + - * / %、比较 == != < <= > >=、逻辑 and / or（短路）与 not / !，以及完整的 C 位运算与三元表达式。

ops.l
let reg = (1 << 4) | 0x03;        // 0x13
let high = (0xCAFE >> 8) & 0xFF;   // 0xCA
let level = (temp > 30) ? "HIGH" : "NORMAL";

控制流

flow.l
if count > 0 {          // 条件表达式不需要圆括号
    print("positive");
} else {
    print("non-positive");
}

for let i = 0; i < 5; i = i + 1 {
    if i == 2 { continue; }   // 支持 break / continue
    print(i);
}

let n = 0;
while n < 3 { n = n + 1; }

02 函数

一等函数与词法闭包

函数可以赋值、传参、返回，也能捕获定义时的外层变量。

counter.l
fn make_counter(start) {
    let n = start;
    return fn(step) {
        n = n + step;
        return n;
    };
}

let c = make_counter(10);
print(c(5), c(3));      // 15 18
methods.l
print("  hello esp32  ".trim().upper().split(" "));
// ["HELLO", "ESP32"]

print([3, 1, 4, 2].sort().map(fn(x) { return x * 10; }));
// [10, 20, 30, 40]

let sensor = {
    addr: 0x3C,
    scale: 2,
    read: fn(raw) { return raw * self.scale; }
};
print(sensor.read(21));  // 42

Map 方法里可以直接用隐式绑定 self，也可以显式写成 fn(self, ...)。

03 异常

结构化的 try / catch / throw

任何语法或运行时错误都会生成一个异常对象，带类型、消息、文件、行、列、源码行与调用栈。

except.l
try {
    throw { code: 500, message: "传感器响应超时" };
} catch (e) {
    print(e.type, e.message);
    print(e.file + ":" + str(e.line) + ":" + str(e.col));
    print(e.source);   // 出错那一行的源码
    print(e.stack);    // 调用栈字符串
}
未捕获时的输出格式
[sensor.l:12:16] 运行时错误: 除数不能为 0
    12 |     return 100 / scale;
       |                ^
  调用栈回溯:
    at read_sensor (sensor.l:12:16)
    at main_loop (sensor.l:20:14)
    at <main> (sensor.l:25:1)

退出码区分错误类型：65 语法错误、70 运行时错误、74 文件无法读取，方便脚本外层做重试。

04 模块

import 与字节码

内置硬件模块不需要文件系统；本地模块按路径导入，自动缓存，支持 as 别名。

import.l
import "esp32" as hw;          // 内置硬件模块
import "./utils/math_ext.l" as m;

print(m.clamp(ADC(34).read(), 0, 4095));
bytecode
l -c main.l -o main.lc    # 编译为紧凑字节码
l main.lc                 # 直接运行字节码
l -d main.l               # 反汇编查看操作码

字节码文件可写入 l_script 分区，LBC1 魔数会走栈式虚拟机执行，省去板端词法与语法分析。

05 硬件

外设对象速查

所有硬件对象的构造与真机一致；在 PC 上运行时由 host-sim 层接管，可以注入模拟数据。

Pin 数字引脚

Pin(pin, [mode="out"], [val]) 或简写 pin(pin)。模式："out"、"in"、"in_pullup"、"in_pulldown"、"open_drain"。

方法：.on() / .high()、.off() / .low()、.toggle()、.value([0|1])、.mode([m])、.info()。修改配置会返回自身，可直接链式调用。

PWM 脉冲宽度调制

PWM(pin, [freq=1000], [duty=0])，10 位分辨率占空比 0..1023。

方法：.freq([hz])、.duty([0..1023])、.duty_percent([0..100])、.stop() / .deinit()。

ADC 模拟采样

ADC(pin, [atten="11db"])，构造时校验引脚是否具备 ADC 通道。

方法：.read()（0..4095）、.read_mv()（毫伏）、.read_uv()（微伏）、.atten(db)、.write_sim(raw)（仿真注入）。

I2C 总线与寄存器

I2C([bus=0], [sda], [scl], [freq])。

方法：.scan()、.write(addr, data)、.read(addr, len)、.write_reg(addr, reg, data)、.read_reg(addr, reg, len)、.sim_device(addr)。

SPI 全双工收发

SPI([bus=1], [sck], [mosi], [miso], [freq])。

方法：.transfer(data) / .xfer(data)（收发并返回 bytes）、.write(data)、.read(len, [fill])。

UART 串口通信

UART([port=1], [baud=115200], [tx], [rx])。

方法：.write(data)、.any()、.read([len])、.read_str()、.sim_input(data)。

bytes 定长字节缓冲

bytes(len | array | str)，支持下标读写 b[0] = 0xFF。

方法：.len()、.hex([sep])、.to_str()、.to_array()、.fill(b)、.slice(s, [e])、.u16_be(off)、.u16_le(off)、.set_u16_be(off, v)、.set_u16_le(off, v)。

ESP32 基础功能类

方法说明
ESP32.chip() / .version()芯片型号与 ESP-IDF 版本
ESP32.info()完整硬件字典：架构、核心数、主频、SRAM、Flash、PSRAM、堆、MAC
ESP32.pin_info(pin) / .pins() / .pinout()单引脚能力 / 分类汇总 / 终端打印整块芯片引脚表
ESP32.set_chip(型号)PC 仿真时切换目标芯片，自动套用对应引脚约束
ESP32.freq([MHz]) / .free_heap()读写主频（40/80/160/240）/ 剩余堆字节数
ESP32.ticks_ms() / .delay_ms(ms)启动以来毫秒计数 / 毫秒级延时
ESP32.crc32(data)IEEE 802.3 CRC32 校验值
ESP32.flash_write(code) / .flash_exec()带 16B 头与 CRC32 写入 l_script 分区 / 零拷贝执行

ports() / upload(port, file) / connect(port)扫描串口 / 串口烧录脚本 / 连接板端 REPL

06 网络与服务端

WiFi 与 Web 服务端

联网、对时、HTTP 客户端与轻量级 TCP/Web 服务端都在标准库中；PC 模拟与 ESP32 真机无缝切换。

函数 / 类说明返回 / 方法
wifi_connect(ssid, [pwd], [to])连接 WiFi 热点true / false
wifi_disconnect() / wifi_is_connected()断开 / 查询连接状态bool
wifi_ip() / wifi_mac()局域网 IPv4 地址 / 网卡物理 MAC字符串或 nil
wifi_ap(ssid, [pwd])开启 SoftAP 本地热点（默认 192.168.4.1）true
wifi_scan()扫描周围 WiFi 热点[{ssid, rssi, auth}, ...]
http_get(url, [timeout_ms])发起 HTTP / HTTPS GET 请求{status, body, ok}
http_post(url, [body], [hdr], [to])发起 HTTP / HTTPS POST 请求{status, body, ok}
sntp_sync([server], [timeout])网络对时，之后 time() 返回真实时间true / false
Tcp(host, port, [timeout_ms])TCP 客户端连接.send() / .recv() / .close()
TcpServer(port, [host], [backlog])TCP / Web 服务端监听.accept([timeout_ms]) / .close()
http_server.l (轻量 Web 控制后台)
let server = TcpServer(8080);
print("Web 控制台已启动: http://127.0.0.1:8080/");

while true {
    // accept 带 1000ms 超时, 非阻塞等待客户端, 不卡死 CPU 与外设心跳
    let client = server.accept(1000);
    if client != nil {
        let req = client.recv(2048, 1000);
        if req != nil and req.find("GET /toggle") >= 0 {
            Pin(2).toggle();
        }
        let body = "<h1>ESP32 控制面板</h1><p><a href='/toggle'>切换板载 LED</a></p>";
        let resp = "HTTP/1.1 200 OK\r\nContent-Type: text/html; charset=utf-8\r\n\r\n" + body;
        client.send(resp);
        client.close();
    }
}

07 蓝牙

BLE 低功耗蓝牙通信

内置全局 BLE 对象，支持 GATT 从机广播、手机 App 连接与无线数据双向透传；PC 宿主内置离线仿真状态机。

方法说明示例 / 返回
BLE.init([name="L-Lang-BLE"])初始化蓝牙协议栈并配置设备广播名称true
BLE.deinit()释放蓝牙协议栈资源true
BLE.adv_start([adv_name])开启广播，允许周围手机与上位机发现true
BLE.adv_stop()停止广播true
BLE.is_connected()查询当前是否有客户端建立蓝牙连接bool
BLE.send(数据)向已连接客户端发送数据（支持文本或 bytes）自身 (支持链式)
BLE.recv([max_len], [timeout_ms])接收客户端写入的数据，超时返回 nil字符串或 nil
BLE.recv_bytes([max_len], [to])二进制安全接收 bytes 数据bytes 或 nil
BLE.status()查询当前运行状态字典{initialized, advertising, connected, ...}
ble_controller.l (手机蓝牙透传控制)
BLE.init("ESP32-SmartNode");
BLE.adv_start();
print("BLE 广播已开启，可用手机 App (如 nRF Connect) 搜索连接...");

while true {
    if BLE.is_connected() {
        let cmd = BLE.recv(128, 100);
        if cmd == "LED_ON" {
            Pin(2).on();
            BLE.send("OK: LED 已点亮\n");
        } else if cmd == "LED_OFF" {
            Pin(2).off();
            BLE.send("OK: LED 已熄灭\n");
        }
    }
    ESP32.delay_ms(100);
}

08 生态

传感器与开源驱动库

纯 L 语言实现，零 C 编译门槛！开源标准驱动库位于仓库 examples/drivers/，开箱即用。

外设型号通讯接口驱动文件功能与特性
SSD1306I2Cexamples/drivers/SSD1306.l0.96 寸 128x64 OLED 屏幕驱动，内置 1KB 显存缓冲与 5x7 ASCII 字符点阵绘制
AHT20I2Cexamples/drivers/AHT20.l高精度温湿度传感器驱动，支持 20 位原码校验解析，输出温度 (℃) 与湿度 (%RH)
WS2812单总线 GPIOexamples/drivers/WS2812.lRGB 幻彩全彩灯珠驱动，支持 GRB 色彩缓冲与彩虹渐变色轮算法 wheel()
综合演示多总线联动examples/drivers/demo_all.l多传感器协同工作站示例：OLED 实时绘制温湿度曲线并同步指示灯
weather_station.l (温湿度采集与 OLED 显示)
import "./examples/drivers/SSD1306.l" as oled;
import "./examples/drivers/AHT20.l" as aht;

// 初始化 I2C 总线 (ESP32: SDA=21, SCL=22)
let i2c = I2C(0, 21, 22);
let screen = oled.SSD1306(i2c);
let sensor = aht.AHT20(i2c);

screen.clear();
screen.text("L-Lang Station", 8, 4);
screen.show();

while true {
    let env = sensor.read();
    screen.clear();
    screen.text("Temp: " + str(env.temp) + " C", 0, 16);
    screen.text("Humi: " + str(env.humi) + " %", 0, 32);
    screen.show();
    ESP32.delay_ms(2000);
}
