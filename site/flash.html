Web Flasher

浏览器免驱动连接 ESP32

无需配置 ESP-IDF 或 Python 环境。使用 Chrome 或 Edge 浏览器，不仅能下载与刷入底包固件，还能直接通过 Web Serial 串口以 0.2 秒极速将 .l 脚本写入板端 Flash 裸分区，并进行板端实时交互！

01 首次准备

下载并刷入底包固件（每块板只需做一次）

如果你的板子尚未刷入 L 语言固件，请先根据芯片型号下载合并固件（从地址 0x0 一次写入）：

ESP32 l-esp32-merged.bin 经典 ESP32 · 刷写地址 0x0 ESP32-C3 l-esp32c3-merged.bin RISC-V · 刷写地址 0x0 ESP32-S3 l-esp32s3-merged.bin 双核 LX7 · 刷写地址 0x0 ESP32-C6 l-esp32c6-merged.bin Wi-Fi 6 / RISC-V · 刷写地址 0x0
打开乐鑫官方网页刷机工具 (ESP Web Flasher) 查看详细刷机指引

02 日常烧录与交互

网页串口工作台 (Web Serial)

底包刷好后，日常修改 .l 脚本完全不需要重新编译固件。连接串口后，点击「一键烧录」即可在 0.2 秒内热更新至 l_script 分区并立即执行。

未连接串口
[未连接串口] 请使用 Chrome 或 Edge 浏览器，点击上方「连接 ESP32 串口」按钮...

烧录通信协议：先握手 __L_UPLOAD_BEGIN__ 并预检 __L_UPLOAD_READY__，源码按 64 字节分块传输并执行硬件级 IEEE 802.3 CRC32 校验，断电不丢失，上电自动运行。
