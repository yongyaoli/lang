Firmware

底包刷一次，脚本改一辈子

每块开发板只需刷入一次 L 底包固件。之后修改 .l 脚本通过串口 0.2 秒写入并立即运行，不需要重新编译固件，也不需要挂载文件系统。

01 下载

选择你的芯片

文件均为合并后的单文件固件，从地址 0x0 一次写入 bootloader、分区表与应用。

ESP32 l-esp32-merged.bin 经典 ESP32 · 刷写地址 0x0 ESP32-C3 l-esp32c3-merged.bin RISC-V · 刷写地址 0x0 ESP32-S3 l-esp32s3-merged.bin 双核 LX7 · 刷写地址 0x0 ESP32-C6 l-esp32c6-merged.bin Wi-Fi 6 / RISC-V · 刷写地址 0x0

全系单固件直刷：以上固件已全部由云端 CI 自动完成编译与打包（涵盖 ESP32、C3、S3、C6），统一在 0x0 地址刷写即可。底包只刷一次，日常写脚本通过裸 Flash 机制 0.2 秒写入并自动运行。

02 首次刷机

三步完成

只需要 Chrome 或 Edge 浏览器，不用安装 ESP-IDF，也不用装 Python。

  1. 下载对应芯片的 .bin

    不确定型号就看板子丝印，或插上 USB 后看串口日志里的芯片信息。

  2. 打开网页刷机工具并连接串口

    用 Chrome / Edge 打开乐鑫官方 ESP Web Flasher，点击 Connect 选择开发板串口。

  3. 刷写地址填 0x0，选择文件后点 Flash

    等待进度条结束，板子自动复位并进入 L 的 REPL。

打开站内网页烧录器 乐鑫官方刷机工具 (esptool-js)

命令行刷写

已经装了 esptool.py 的话，一条命令即可：

esptool
esptool.py --port COM3 write_flash 0x0 l-esp32-merged.bin

# macOS / Linux 串口形如 /dev/ttyUSB0 或 /dev/cu.usbserial-*

03 日常烧录

改脚本不用再刷固件

三种方式，任选一种。写入前会擦除分区，写入后用 IEEE 802.3 CRC32 校验，校验通过才执行。

REPL 内烧录

>>>
ports();
upload("COM3", "main.l");
connect("COM3");

命令行烧录

terminal
l -p                 # 列出串口
l -u COM3 main.l     # 烧录并运行
l -s COM3            # 远程终端

浏览器烧录

Web Serial
// 网页里粘贴脚本，点「一键烧录」
// 走同一条 __L_UPLOAD_BEGIN__ 协议
pin(2).on();
print(ESP32.chip());

串口握手会先发 __L_UPLOAD_READY__，脚本按 64 字节分块写入并统一为 LF 换行，避免 CRC32 不一致。

04 分区

脚本存在哪

自定义数据分区 l_script（子类型 0x99）专门存放脚本，不挂载任何文件系统。

分区类型大小
nvsdata / nvs0x6000
phy_initdata / phy0x1000
factoryapp / factory2M
l_scriptdata / 0x99128K

分区头部 16 字节：magic（LSCR 源码 / LBC1 字节码）、length、crc32、flags。上电时若魔数与校验都有效，直接用 esp_partition_mmap 映射执行，源码不会拷贝进 SRAM。

解析、报错回显、字节码执行都直接读 Flash 映射区，320 KB SRAM 全部留给业务逻辑。
