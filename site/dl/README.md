# 本地下发资源目录 (site/dl/)

本目录用于存放官网离线或本地直链下载的构建产物。
若启用了 GitHub Releases，页面会默认通过 `releases/latest/download/<文件名>` 从 GitHub 官方 Release 资产高速下载。

### 对应产物列表

- `lang-setup-windows-x86_64.exe` (Windows 安装包)
- `lang-windows-x86_64.zip` (Windows 免安装便携包)
- `lang-linux-x86_64.tar.gz` (Linux 预编译包)
- `lang-macos-arm64.tar.gz` (Apple Silicon M 系列预编译包)
- `lang-macos-x86_64.tar.gz` (Intel Mac 预编译包)
- `lang-unix.zip` (Unix 通用源码包)
- `l-esp32-merged.bin` (经典 ESP32 单文件合并固件)
- `l-esp32c3-merged.bin` (ESP32-C3 单文件合并固件)
- `l-esp32s3-merged.bin` (ESP32-S3 单文件合并固件)
- `l-esp32c6-merged.bin` (ESP32-C6 单文件合并固件)
