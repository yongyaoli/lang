写一行脚本，
点亮一块芯片。

L（lang）是一门用纯 C99 从零实现的超轻量脚本语言。没有任何第三方依赖，同一份 .l 脚本，既能在 ESP32 真机上驱动 GPIO、PWM、ADC、I2C、SPI、UART，也能在 Windows / Linux / macOS 上离线仿真。

01 三十秒上手

不用装 IDE，不用配工程

一个解释器、一个 .l 文件、一块开发板。末尾的分号可以省略，跨行代码块会自动识别。

blink.l
const LED = 2;

pin(LED).on();                 // 点亮板载 LED
PWM(LED, 5000, 512);           // 5 kHz, 50% 占空比

print(ESP32.chip());           // ESP32 / ESP32-S3 / ESP32-C3 / ESP32-C6
print(ESP32.free_heap(), "B"); // 剩余堆内存

try {
    Pin(6, "out");             // GPIO 6 属于内部 SPI Flash
} catch (e) {
    print(e.message);          // 被引脚安全护栏拦下
}
示例输出
$ l blink.l
ESP32-S3
198432 B
[blink.l:9:3] 运行时错误: GPIO 6 属于内部 SPI Flash，禁止作为输出
    9 |     Pin(6, "out");             // GPIO 6 属于内部 SPI Flash
      |     ^

手边没有开发板也能跑：l 会自动进入 host-sim 模式，硬件调用由 PC 端模拟执行，脚本逻辑一行都不用改。

02 为什么是 L

把复杂度留在解释器里，
把简单留给写脚本的人

嵌入式开发的麻烦通常不在业务逻辑，而在工具链、文件系统、烧录与调试。L 把这些一次性收进底包固件。

01

零依赖，一行命令编译

不依赖 lex、yacc、LLVM 或任何外部库。整个解释器加标准库只有数千行 C99，GCC / Clang / MSVC / ESP-IDF 都能直接编。

02

一份脚本，两种运行环境

统一硬件抽象层 l_hal.h：真机走 ESP-IDF 驱动，电脑走 host-sim 模拟。ESP32.set_chip("ESP32-C3") 还能切换目标芯片的引脚规则。

03

裸 Flash 存脚本，不挂文件系统

l_script 自定义分区 + 16 字节头 + IEEE 802.3 CRC32 校验，用 esp_partition_mmap 零 SRAM 拷贝直接执行，上电自启动。

04

0.2 秒改一次代码

底包固件只刷一次。之后 upload("COM3", "main.l") 串口直传，或在浏览器里用 Web Serial 直接烧录，不需要重编固件。

05

报错精确到列

[文件:行:列] + 源码行 + ^ 指示符 + 完整调用栈，配合 try / catch 做异常自恢复，告别嵌入式盲猜调试。

06

VS Code / CodeBuddy 一体化支持

官方扩展提供语法高亮、类与方法 Hover、Ctrl+Click 跳转定义、CodeLens 引用计数与 .l 文件专属图标。Windows 安装包自动注册扩展并关联文件，装完即得 IDE 体验。

语法错误、运行时错误、未捕获异常都走同一套诊断格式，行号与列号直接指向出错的那一个字符。

03 从脚本到芯片

固件只刷一次，之后只传脚本

首次用 esptool 或浏览器刷入合并固件；日常改代码走串口，0.2 秒完成写入、CRC32 校验与热重载。

main.l本地脚本
→
l -u COM3串口 0.2 秒
→
l_script裸 Flash 分区
→
GPIO / I2C上电自启动

硬件对象都是普通对象

没有特殊的语法糖：pin(2).on() 就是方法调用，能链式、能赋值、能塞进数组与字典，也能被闭包捕获。

对象典型用法
Pinpin(2).on().toggle()
PWMPWM(2, 5000, 512)
ADCADC(34).read_mv()
I2Ci2c.write_reg(0x3C, 0x00, buf)
SPIspi.transfer(bytes(4))
UARTuart.read_str()
bytesb.set_u16_be(0, 0x1234)
i2c_oled.l
let i2c = I2C(0, 21, 22, 400000);
i2c.sim_device(0x3C);                    // PC 模式下注册模拟从机

i2c.write_reg(0x3C, 0x00, bytes([0xAE, 0xD5]));
print("读回:", i2c.read_reg(0x3C, 0x00, 2).hex(" "));

print(ADC(34).read_mv(), "mV");
UART(1, 115200, 17, 16).write("hello\n");

支持 import "esp32" 直接引内置硬件模块，裸机上不需要文件系统。

两条路，选一条开始
