Install

装好 l，只要一条命令

支持 Windows、Linux、macOS。安装程序会自动部署解释器与标准库、写入 PATH 并关联 .l 文件；整个过程不需要任何预装运行时。

01 选择平台

Windows 安装包 推荐 lang-setup-windows-x86_64.exe Windows 10/11 · x64 免安装便携包 lang-windows-x86_64.zip 解压即用，不写注册表

用安装包（最简单）

  1. 下载并双击运行安装程序

    默认安装到 %LOCALAPPDATA%\Programs\lang，无需管理员权限。

  2. 跟随向导完成，PATH 自动配置

    安装器会勾选并写入用户级 PATH，同时在「应用和功能」中注册，可随时一键卸载。

  3. 打开新的终端窗口

    已经打开的窗口不会继承新的 PATH，请新开一个 CMD 或 PowerShell。

PowerShell
PS> l --version
L 0.1.9

PS> l
Type "help", "copyright", "license" or "exit" for more information.
ESP32 快捷命令: ports() | upload("COM3", "main.l") | connect("COM3") | help("esp32")
>>>

若发布页尚未附带安装包，可改用下方的命令行脚本安装，或直接源码编译（第三个标签）。

用脚本安装

PowerShell
git clone https://github.com/yongyaoli/lang
cd lang
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
Linux x86_64 lang-linux-x86_64.tar.gz 预编译二进制 · 含 install.sh macOS Apple Silicon lang-macos-arm64.tar.gz M1 / M2 / M3 / M4 · 预编译 macOS Intel lang-macos-x86_64.tar.gz x86_64 · 预编译

解压后执行 bash install.sh 即可。其他架构（ARM 服务器、RISC-V）请用 lang-unix.zip 源码包或源码编译。

一键脚本

脚本会自动检测系统与架构、编译或解压对应的二进制，并把 l 放到可执行路径下。

bash
git clone https://github.com/yongyaoli/lang
cd lang
bash ./scripts/install.sh

安装位置规则

1. 有 sudo 权限时优先安装到 /usr/local/bin/l；
2. 无 root 权限时自动回退到 ~/.local/bin/l；
3. 自动检测并在 ~/.bashrc、~/.zshrc 或 ~/.profile 中补 PATH。

卸载

bash
bash ./scripts/uninstall.sh

macOS 若提示「无法验证开发者」，在「系统设置 → 隐私与安全性」里允许一次即可；也可直接用源码编译绕过。

只要一个 C 编译器

没有 lex、yacc、LLVM，也没有第三方库。下面这条命令就是完整构建过程：

Linux / macOS
gcc -O2 -Wall -Wextra -Isrc/include src/core/*.c src/stdlib/*.c \
    src/main/main.c -o l
Windows · PowerShell
gcc -O2 -Wall -Wextra -Isrc/include src/core/*.c src/stdlib/*.c src/main/main.c `
    -lwininet -lws2_32 -static -o l.exe

裁剪裸机版本

给无文件系统的 ESP32 编译更小的解释器时，可关掉文件与进程模块：
-DL_WITH_STDLIB_IO=0 -DL_WITH_STDLIB_SYS=0

注意：tests/ 与 stdlib/ 的改动需要一起编译；漏掉 bytecode.c、compiler.c、vm.c 会在链接阶段报未定义符号。

02 验证

三条命令确认装好了

terminal
l --version      # 打印版本号
l                # 进入 REPL
l main.l         # 运行脚本文件
期望输出
$ l --version
L 0.1.9

$ l
Type "help", "copyright", "license" or "exit" for more information.
>>> print("hello")
hello

如果提示「找不到命令」，多半是终端没有重新打开，或 PATH 未生效。Windows 可执行 where l，macOS / Linux 用 which l 定位。

03 分发

自己打包一份

想把 l 分发给同事或放进内网，用仓库里的打包脚本一次生成安装包与压缩包。

PowerShell
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
产物用途
lang-setup-windows-x86_64.exeWindows 独立安装程序
lang-windows-x86_64.zipWindows 便携版
lang-unix.zipLinux / macOS 安装包
l-language-support-0.3.0.vsixVS Code 语法高亮与智能提示插件

脚本会先调用 scripts/bump_version.ps1 递增小版本号，再编译并打包，产物统一输出到 dist/。
