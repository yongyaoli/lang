# L Language - Embedded & IoT Support for Visual Studio Code

L 语言（`lang`）官方 VS Code 语法高亮与智能提示插件。

L 是一门用纯 C99 从零手写实现的超轻量嵌入式（ESP32 系列）与通用脚本语言。

---

## 核心特性

- **语法高亮与颜色分层**：
  - 完美识别关键字 `let`、`const`、`fn`、`try`、`catch`、`throw`、`import` 等；
  - 硬件外设类与系统内置单例（`Pin`、`PWM`、`ADC`、`I2C`、`SPI`、`UART`、`Timer`、`ESP32`）青色高亮；
  - 字符串（单双引号）、数字字面量、十六进制 `0x` 与二进制 `0b`。
- **Hover 鼠标悬停提示**：
  - 鼠标移动到 `pin()`、`ESP32.status()`、`bytes` 等内置函数与类上时，自动显示函数签名与中文 API 用法文档；
  - 支持用户自定义函数与类的方法签名提示。
- **跳转到定义 (Go to Definition)**：
  - <kbd>Ctrl</kbd> + 鼠标左键点击自定义函数或变量，直接跳转到源码声明位置。
- **L 专属文件图标**：
  - 自动为 `.l` 脚本文件提供专属优雅图标。
- **右键上下文菜单与快捷运行**：
  - 在 `.l` 编辑器或资源管理器中点击右键，一键执行「本地运行脚本」、「烧录到 ESP32 开发板」、「VM 模式运行」与「编译为字节码」；
  - 编辑器右上角常驻绿色播放与闪电烧录快捷按钮。
- **串口自动检测与串口监视器**：
  - 底部状态栏实时显示当前 ESP32 目标串口，自动智能探测新接入的硬件端口；
  - 内置串口监视终端，点击「串口监视」一键打开实时回显交互终端，免去第三方串口助手切换烦恼。

---

## 快速上手

1. 在 VS Code 中打开任意 `.l` 脚本文件（例如 `main.l`）；
2. 语言模式将自动识别为 `L` 并启用全套高亮与智能提示；
3. 点击编辑器右上角 **`▶`** 或右键选择 **`L: 运行当前脚本`** 即可在终端极速运行；
4. 点击底部状态栏的 **`$(circuit-board) COMx`** 选定开发板串口，右键选择 **`L: 烧录到 ESP32 开发板`** 即可 0.2 秒完成烧录！
