第一步：首次刷入 L 语言 ESP32 底包固件 (.bin) —— 本机零安装

  1. 将代码推送到 GitHub 后，打开仓库的 Actions → Build ESP32 Firmware，下载云端自动编译好的单文件固件（如 l-esp32-merged.bin、l-esp32c3-merged.bin 或 l-esp32s3-merged.bin）。
  2. 使用 Chrome 或 Edge 浏览器打开乐鑫官方网页刷机工具，连接开发板串口，将燒录地址设为 0x0，选择刚才下载的 .bin 文件即可一键刷入（每块板子只需刷一次）：
打开乐鑫官方网页刷机工具 (ESP Web Flasher)
