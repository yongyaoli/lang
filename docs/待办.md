### P3：进阶能力探索（后续演进）

- [x] **轻量服务端支持（HTTP / TCP Server）**
  - 在 `stdlib/net.c` 中扩展实现了 `TcpServer` 类；
  - 支持 `.accept(timeout_ms)`（非阻塞/超时轮询友好）、`.close()`、`.is_listening()` 与 `.info()`；
  - 提供了完整轻量嵌入式 Web 控制后台示例 [`examples/http_server.l`](../examples/http_server.l)，可用于局域网 Web 配网与参数控制看板。
- [x] **BLE（低功耗蓝牙）基础通信**
  - 在 `l_hal.h` 中抽象并统一了 BLE GATT 外设接口；
  - 在 `stdlib/hal.c` 中落地了 ESP-IDF 驱动存根与 PC 离线状态机仿真；
  - 在 `stdlib/hw.c` 中内置注册了全局 `BLE` 对象，支持广播、连接检测、数据双向透传与状态看板。
- [ ] **高效流式 JSON 编解码器（`JSON` 全局对象，M12 规划）**
  - 纯 C99 零外部依赖单趟递归下降解析器，16 层最大嵌套深度硬防护（防止堆栈溢出）；
  - `JSON.parse(str)`：解析为原生 Map/Array 结构，支持行列精确定位报错；
  - `JSON.stringify(val, [pretty])`：序列化原生数据结构，支持紧凑与 2 空格美化模式；
  - 详见 [`docs/改进.md#142-高效流式-json-编解码器json-全局内置对象`](改进.md#142-高效流式-json-编解码器json-全局内置对象)。
- [ ] **嵌入式统一虚拟文件系统（`FS` / `File` 标准库，M13 规划）**
  - 在 ESP32 上集成 LittleFS 分区（掉电安全、磨损均衡，每句柄 <512B RAM），在 PC 宿主透明映射本地磁盘；
  - 全局静态快捷操作：`FS.exists`、`FS.read`、`FS.write`、`FS.append`、`FS.remove`、`FS.list`、`FS.mkdir`、`FS.info`；
  - 流式句柄 `File.open(path, mode)`：逐行读取与分块追加，配合 `import` 真正实现多模块本地解耦；
  - 详见 [`docs/改进.md#143-嵌入式统一虚拟文件系统fs--file-标准库`](改进.md#143-嵌入式统一虚拟文件系统fs--file-标准库)。
- [ ] **MQTT 3.1.1 物联网客户端（`MqttClient` 类，M14 规划）**
  - 基于现有 `l_tcp.h` 跨平台 Socket 抽象层实现极简 MQTT 3.1.1 编解码器，零外部三方依赖；
  - 支持 QoS 0 / QoS 1 发布与订阅、遗嘱消息（LWT）、掉线退避自动重连；
  - 提供 `.poll()` 非阻塞轮询机制，无缝融入协作式事件循环心跳点（`ESP32.delay_ms`）；
  - 详见 [`docs/改进.md#141-mqtt-物联网客户端协议支持mqttclient-类`](改进.md#141-mqtt-物联网客户端协议支持mqttclient-类)。
