# 命令行与 REPL 交互指南

L 语言提供了强大、极简的命令行终端工具 `l`，集成了**代码运行、交互式 REPL、串口极速烧录、端口扫描与远程终端**于一身。

---

## 1. 命令行参数全览 (`l --help`)

| 命令格式 | 功能说明 | 典型示例 |
| :--- | :--- | :--- |
| `l <file.l>` | 运行指定的本地 L 语言脚本 | `l examples/wifi_scan.l` |
| `l` | 无参数进入电脑端交互式 REPL 终端 | `l` |
| `l -e "<code>"` | 单行代码直接求值并输出 | `l -e "print(1 + 2 * 3);"` |
| `l -u <port> <file>`| 将脚本通过串口 0.2s 极速烧录到 ESP32 裸 Flash | `l -u COM3 main.l` |
| `l -s <port>` | 建立与 ESP32 板端的交互式串口远程终端 (REPL) | `l -s COM3` |
| `l -p` | 扫描当前系统所有可用串口并输出状态 | `l -p` |
| `l -v` / `l --version` | 查看当前语言版本、构建时间与著作权声明 | `l -v` |
| `l -h` / `l --help` | 显示命令行完整帮助手册 | `l -h` |

---

## 2. 交互式 REPL 终端

直接输入 `l` 进入交互式环境：
```text
================================================
  L 语言 0.1.14.202611251708 (PC 宿主环境)
  输入 help() 查看内置帮助, 输入 exit 回车退出
================================================
>>> let name = "ESP32";
>>> print("Hello " + name);
Hello ESP32
>>> pin(2).on();
[sim:gpio] pin 2 (out) -> 1
>>> pin(2).read()
1
>>> exit
```

### REPL 特性：
* **表达式自动求值**：不需要写 `print`，直接输入变量名或计算式如 `2 + 3` 即可打印其值；
* **错误保护**：任何语法错、未定义变量都会以红字精确定位，不会导致 REPL 进程退出；
* **全功能硬件模拟**：在 PC REPL 里可以直接操作 `pin()`、`PWM()`、`I2C()`，电脑会实时回显模拟引脚跳变。

---

## 3. 串口远程终端 (`l -s <port>`)

当板子通过 USB 插在电脑上时，执行：
```powershell
l -s COM3
```
电脑控制台将无缝接入 ESP32 板端的真实硬件交互环境：
* **动态指令交互**：直接在终端敲入 `ESP32.status()`、`wifi_scan()`、`pin(2).toggle()`，指令瞬间在芯片上硬件级执行并返回结果；
* **跳过自启动脚本**：开机 1 秒内按 `Ctrl+C` 可跳过已烧录的脚本自启，直接进入纯净控制台；
* **安全退出**：按 `Ctrl+]` 或输入 `.exit` 回车即可安全断开串口连接。
